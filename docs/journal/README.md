# Journal

Narrative session log for this repository, normally one file per local date:
`docs/journal/YYYY-MM-DD.md`.

Record meaningful changes, validation, decisions, findings, unresolved risks,
and resume points. Use `YYYY-MM-DD-topic-slug.md` for a substantial standalone
topic. Keep small follow-ups in the existing daily entry.

The journal preserves the story and evidence. `TODO.md` remains the canonical
current queue.
